📌 FaceMap – AI-Powered Makeup Placement System

FaceMap is a computer vision-based application that analyzes facial features to provide personalized makeup placement guidance. The system detects key facial landmarks such as cheekbones and chin, and visually maps where users should apply blush and contour on their own face image. It also performs basic skin tone analysis to recommend suitable makeup shades.

🚀 Features

🎯 Facial landmark detection using advanced computer vision
💄 Precise blush and contour placement mapping
🎨 Skin tone detection with shade recommendations
🖼️ Visual overlay on user’s face for easy understanding
⚡ Simple and interactive image-based processing

🛠️ Technologies Used

-  Python
-  OpenCV
-  MediaPipe
-  NumPy
-  Matplotlib

⚙️ How It Works

Upload a face image
Detect facial landmarks (cheeks, chin, jawline)
Apply geometric rules to determine makeup placement
Analyze skin tone from facial regions
Display output with visual guides and recommendations
